Regras para Agentes de IA
Objetivo
Este repositório contém atividades escolares, mapas mentais e materiais didáticos.

Antes de criar arquivos
Verificar se já existe conteúdo semelhante.
Atualizar arquivos existentes sempre que possível.
Evitar duplicações.
Não criar arquivos numerados.
Nomenclatura
Utilizar nomes em minúsculas.

Exemplos:

alto-imperio-romano.html baixo-imperio-romano.html revolucao-francesa.html

Estrutura
Cada disciplina possui sua própria pasta.

disciplinas/ ├── historia/ ├── geografia/ ├── sociologia/ └── robotica/

Proibições
Nunca criar:

index_v2.html arquivo-final.html arquivo-final2.html teste.html

Git
Criar branches:

feature/nova-atividade feature/mapa-mental-roma fix/correcao-links refactor/reorganizacao-pastas

Documentação
Sempre atualizar README.md quando novas atividades forem adicionadas.

Atividades
História (disciplinas/historia/)
- index.html: índice da coleção histórica
- ensino-fundamental/historia-antiga/roma-antiga/imperio-romano/imperio-romano-mapa-mental.html: mapa mental do Império Romano
- ensino-fundamental/historia-medieval/feudalismo-mapa-mental.html: mapa mental da Idade Média (Alta e Baixa Idade Média, com resumos clicáveis)

A página inicial do repositório é o index.html da raiz, que apenas aponta para as atividades de cada disciplina.
